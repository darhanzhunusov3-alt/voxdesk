# WOK Studio

Браузерная студия записи и сведения в стиле BandLab: треки с громкостью и панорамой прямо в заголовке,
цепочка эффектов трека в нижней панели, бит (Channel Rack), запись с микрофона, автотюн
и твои плагины VocalChain и ShkaFX.

## Как запустить

Микрофон в браузере работает только по https или с локального сервера.

**GitHub Pages (удобнее всего, работает и с телефона):**
1. Залей папку в репозиторий на GitHub.
2. Settings → Pages → Branch: `main`, папка `/root` → Save.
3. Через минуту студия откроется по адресу `https://<ник>.github.io/<репозиторий>/`.

**Локально:** в папке проекта выполни `python -m http.server 8000`
и открой `http://localhost:8000` в Chrome.

## Что умеет

- **Транспорт:** ● запись, ▶/⏸ (пауза оставляет курсор на месте), ⏮ в начало, ⟳ цикл, таймер 00:00.0,
  громкость мастера, метроном. Курсор тянется по линейке зажатой мышью или пальцем.
  **Цикл без пауз на стыке:** включи ⟳ (или L) — цикл на 4 такта от курсора; края и середину тяни на линейке,
  Shift+протяжка рисует новый цикл, двойной клик по линейке сбрасывает цикл.
- **Автокей:** при импорте бита (на трек «Бит» или файл с «beat»/«бит» в имени) студия сама определяет его
  тональность и ставит её в KEY и во все автотюны.
- **KEY:** тональность проекта в шапке — сразу у всех автотюнов (и у новых тоже). Размер — 4/4.
- **Треки:** номер, имя, капсула «Fx» (эффекты трека), M / S / ●, ползунок громкости, ручка панорамы,
  индикатор уровня; ⋯ — имя, цвет, канал микшера, ↑/↓, дублировать, удалить. Двойной клик по имени — переименовать.
  Порядок треков меняется перетаскиванием за иконку трека.
- **Импорт аудио:** «⤓ Импорт аудио» в панели таймлайна (на выбранный трек), тап по пустой дорожке «Бит» (бит с 1-го такта
  и автоопределение тональности) или «Загрузить аудио» в меню ⋯ трека — открывается выбор файлов устройства (Файлы на iOS, Документы на Android).
- **Таймлайн:** клипы с волной, перетаскивание (Alt — без привязки к сетке),
  обрезка краёв, fade in/out (кружки в углах клипа), разрезать по курсору (S), удалить (Delete или ✕).
- **Проект:** сохранить/открыть одним файлом `.wok.zip` (внутри project.json и все записи в WAV;
  старые `.voxdesk.zip` тоже открываются), Ctrl+Z / Ctrl+Y, автосохранение в браузере с предложением восстановить.
  Новый проект начинается с пустым паттерном — Play ничего не играет, пока не поставишь шаги.
- **Запись:** включи ● на треке (или просто выбери трек) и нажми запись (R). Пишется сухой голос, эффекты — при воспроизведении.
  Задержка компенсируется автоматически, точная поправка — во вкладке «Запись» нижней панели.
- **Мониторинг:** слышать себя через эффекты дорожки в реальном времени.
- **Автотюн (YIN + PSOLA):** пресеты Лёгкий / Средний / Жёсткий («Жёсткий» = Auto-Tune Pro Classic,
  Retune 0), Retune Speed, Humanize, Flex-Tune, Tracking, Transpose, тип голоса, тональность и лад,
  опорная частота A4 415.3–466.2 Гц (кнопки 432 / 440) — для битов со сдвинутым строем.
  Кусочки голоса выравниваются по форме волны и сшиваются плавно — без щелчков на стыках нот и согласных.
- **VocalChain 1.2 — оригинальный:** тот же C++ код, что в VST для FL Studio, собран в WebAssembly.
  Окно — его родной интерфейс. Задержка шумодава 30 мс компенсируется.
- **ShkaFX 3.4.1 — оригинальный:** хвосты на первый слог, Delay A/B на слова, Throw, Pan, экспорт.
  Пока песня играет, плагин записывает волну дорожки, как в FL. Окно — родной интерфейс,
  работает без ключа. Экспорт кладёт файлы в «Загрузки» и сразу в «Аудио в проекте».
- **Плагины студии:** EQ (7 полос, точки на графике), Reverb, Delay (пинг-понг, drive), Chorus,
  Soft Clipper (стоит на мастере).
- **Нижняя панель «Эффекты»:** канал трека (громкость, панорама, M/S, уровень), цепочка до 8 эффектов карточками
  (вкл/выкл, открыть, убрать, «Добавить эффект»), посылы в Send Reverb / Send Delay (клик по имени или ⚙ — настройки
  ревера: Decay, Size, Pre-delay, Damping, срезы; дилея: время по темпу или в мс, Feedback, срезы, пинг-понг), «+ Посыл».
  Любой канал, включая Мастер и возвраты, выбирается в списке «Канал». Окна плагинов открываются поверх студии
  (закрыть — ×, Esc или клик по фону).
- **Маршрутизация:** «Выход в мастер» и «В канал…» направляют канал в любой другой (шины); петли не создаются,
  задержка плагинов выравнивается по всем путям — голос, идущий и напрямую, и через шину, не «гребёнит».
  Solo оставляет слышимым всё, что связано с каналом.
- **Дублирование:** ⧉ у дорожки или Ctrl+D — дорожка вместе с каналом микшера и эффектами.
- **Бит (Channel Rack):** вкладка «Бит» нижней панели, 16-шаговый паттерн (Kick, Clap, хэты, 808), шаги сгруппированы по 4.
- **Экспорт WAV** всего проекта.
- **Телефон:** бар режимов снизу Треки / Эффекты / Бит / Запись; транспорт первым в шапке; заголовки треков компактные
  (громкость, панорама, цвет — в шторке по тапу на имя); Rack сеткой 8×2 без прокрутки вбок, шаги тапом и свайпом;
  окна плагинов на весь экран.

## Темы оформления

⚙ в шапке (или «Настройки…» в меню проекта) → «Тема оформления»: **BandLab Classic** (по умолчанию) или **Obsidian Signal**
(холодный графит и мятный неон). Тема меняется сразу и запоминается в этом браузере.

## Горячие клавиши

Пробел — play/pause · Home — в начало · R — запись · L — цикл · S — разрезать · Ctrl+D — дублировать ·
Ctrl+Z / Ctrl+Y — отмена · Ctrl+S — сохранить · Ctrl+O — открыть · F9 — эффекты трека · F6 — бит ·
F8 — библиотека · Esc — закрыть окно плагина · Delete — удалить клип

## Структура

```
index.html          разметка
css/theme.css       цвета, градиенты, тени, шрифты, размеры (дизайн правится здесь)
css/app.css         раскладка и компоненты
js/worklets.js      звук в реальном времени: автотюн, VocalChain, ShkaFX, запись
js/engine.js        движок: микшер, посылы, эффекты, транспорт, экспорт
js/project.js       отмена, сохранение и открытие проекта, автосохранение
js/ui.js            интерфейс
js/shka-worker.js   фоновая часть ShkaFX (расчёт хвостов)
js/vc-bundle.js     VocalChain: wasm + родной интерфейс (генерируется)
js/shka-bundle.js   ShkaFX: wasm + родной интерфейс (генерируется)
plugins/vocalchain/ упаковка VocalChain: ui/, web/build.sh, pack.py
plugins/shkafx/     упаковка ShkaFX: ui/, web/build.sh, web/patch.py, pack.py
DESIGN.md           правила и готовый запрос для нейросети, которая правит дизайн
build.py            собирает всё в один файл dist/index.html (+ claude-artifacts/ — фрагмент для артефакта Claude)
capacitor.config.json, android/, ios/   мобильные приложения (Capacitor)
```

## Как обновить плагины

**VocalChain:** поменял интерфейс — скопируй `ui/index.html`, `style.css`, `app.js` в `plugins/vocalchain/ui/`;
поменял звук — собери wasm по `plugins/vocalchain/web/build.sh`. Затем `python3 plugins/vocalchain/pack.py`.

**ShkaFX:** интерфейс — скопируй `ui/` плагина (вместе со шрифтами) в `plugins/shkafx/ui/`;
звук — `SDK=… SHKA=/путь/к/ShkaFX sh plugins/shkafx/web/build.sh` (сам скопирует исходники и
отключит фоновый поток, его заменяет Web Worker). Затем `python3 plugins/shkafx/pack.py`.

В конце — `python3 build.py`.

## Мобильные приложения

`npm install` один раз, затем `npm run sync` — пересобрать студию и обновить проекты `android/` и `ios/`.
- **iOS:** собирается в GitHub Actions (workflow «Build iOS») при push в main или вручную: Actions → Build iOS → Run workflow.
  Готовый `VoxDesk-unsigned.ipa` — в Artifacts запуска; установить на iPhone — Sideloadly или AltStore с бесплатным Apple ID.
- **Android:** `npx cap open android` в Android Studio → Build → Build APK.
